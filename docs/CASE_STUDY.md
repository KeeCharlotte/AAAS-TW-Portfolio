## 2. 讀者可以自行重跑的程式實作

本庫完整公開[政策模組](../src/domain/accounting/posting_policy.py)與[配套測試](../tests/test_posting_policy.py)，讓讀者檢查資料結構、金額處理、拒絕條件與測試設計。

獨立模組範例使用未稅 101 元、稅額 5 元、總額 106 元；通過條件時產生 106／101／5 的分錄建議。這與上面的 210 元完整系統案例是不同測試。

| 改變輸入 | 模組結果 |
|---|---|
| 缺少來源識別或必要驗證狀態 | 不產生分錄，要求補足來源 |
| 應收帳款被對應為負債、正常貸方 | 不產生分錄，回報科目語意不符 |
| 總額改為 106.01 元 | 不產生分錄，回報金額不一致 |
| 組織政策建立者與核准者相同 | 不產生分錄，回報核准條件不符 |

模組使用 `Decimal` 處理金額；它信任呼叫端提供的來源與核准狀態，不自行驗證原始文件、認證身分或寫入帳簿。成功結果為 `proposed`，`posting_allowed=True` 只表示通過這個函式的判定。組織政策要求 `synthetic_test_fixture_only_not_professional`，專業政策適用性仍未核定。
