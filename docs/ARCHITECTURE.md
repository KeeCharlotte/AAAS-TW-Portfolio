# 架構與公開範圍

本庫從 AAAS-TW 擷取完整會計政策判定模組與配套測試，保留核心程式；另加獨立執行所需的套件與設定。

| 處理位置 | 責任 | 本庫是否包含 |
|---|---|---|
| 判定前 | 取得交易、來源驗證狀態、政策與科目對應 | 僅合成輸入，沒有外部接入 |
| 政策判定 | 檢查條件，回傳分錄建議或拒絕原因 | 完整模組與測試 |
| 判定後 | 覆核、權限檢查、資料庫過帳與追溯 | 未包含 |

## 程式入口

- `PostingPolicyInput`：交易事實與來源狀態。
- `PostingAccountMapping` 及政策資料物件：科目對應與政策條件。
- `evaluate_posting_policy`：執行判定。
- `PostingPolicyResult`：分錄建議、狀態及錯誤原因。

定義見 [政策模組](../src/domain/accounting/posting_policy.py)。

這是一個不連線的函式模組，執行時不呼叫 AI。完整系統、資料庫、部署與工作歷史留在私人專案。測試通過所支持的是這個公開範圍的行為；完整流程是否可用，仍需另外驗證。
