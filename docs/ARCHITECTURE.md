# 完整功能、公開範圍與待辦

AAAS-TW 的主線是：**來源文件 → 會計草稿 → 人工覆核與補件 → 過帳 → 對帳及異常處理 → 匯出結果與佐證。**

目前支援範圍限於臺灣、新臺幣的部分國內企業銷貨，以及無進項營業稅的進貨／費用。以下「有實作」表示私人專案存在程式與操作路徑；是否通過驗證仍須對照版本，不能推算為整套產品已完成。

## 已實作到哪裡？

| 功能 | 私人專案現況 | 本庫揭露 |
|---|---|---|
| 登入與資料權限 | **有實作**：密碼登入、工作階段撤銷、操作分權與組織資料隔離；最新安全修正待完整回歸 | 功能摘要 |
| 來源接收與查閱 | **部分實作**：測試來源上傳、下載與雜湊核對；真實來源及正式儲存未完整接通 | 案例畫面 |
| 會計草稿與政策判定 | **有實作**：必要條件、科目語意與金額檢查；交易類型及政策適用範圍受限 | **完整政策程式與測試** |
| 覆核、退回與補件 | **有實作**：保留舊版，補件建立新版，重新獨立確認及覆核 | 三人流程案例與畫面 |
| 過帳、更正與期間控制 | **有實作**：核准後過帳、收付款結算、沖回／替代更正、關帳／重開；最新各分支仍需驗收 | 過帳畫面與 CSV |
| 銀行對帳與異常 | **部分實作**：合成銀行資料、獨立確認配對、佐證結案及重開；真實銀行未接通 | 操作結果摘要 |
| 歷程與結果匯出 | **有實作**：來源／版本／決策紀錄，CSV 建立、下載與獨立交付紀錄 | 合成 CSV 與案例 |
| 佐證資料包與離線驗證 | **部分實作**：限定事件揭露、指定審查者與期限、本地一致性驗證；工作台交付尚未接通離線工具 | 功能摘要 |
| 使用者工作台 | **部分實作**：待辦、明細與主要會計操作，已有瀏覽器流程實證；未涵蓋全部目標介面 | 實際畫面 |
| 維運與故障恢復 | **有實作**：查回原操作、重送不重複執行、背景工作逾時及資料庫更新中斷恢復；正式環境未驗收 | 功能摘要 |
| AI 財務變更控制 | **內部實驗**：限制 AI 變更、保留檢查與依據；未作為對外預設功能 | 功能摘要 |
| 外部來源、AI 辨識與採信 | **尚未完整接通**：部分僅介面／契約／提案；真實 OCR、ERP／Excel／Gmail 接入及外部採信仍有缺口 | 缺口說明 |

目前的實證是指定歷史版本的合成流程，見[代表案例](CASE_STUDY.md)與[結果紀錄](../evidence/RESULTS.json)。最新安全修正已實作，但尚未完成整體回歸；真實試用、專業政策採信與正式上線仍未成立。

## 公開哪些程式？

公開 [`posting_policy.py`](../src/domain/accounting/posting_policy.py) 與[完整配套測試](../tests/test_posting_policy.py)，另附必要設定。`evaluate_posting_policy` 接收交易、政策與科目資料，回傳分錄建議或拒絕原因；不連線，也不呼叫 AI。

其餘程式、資料庫、部署設定與工作歷史保留私人。上表與畫面用來交代完整範圍；公開測試可自行重跑的部分限於政策模組。模組信任呼叫端提供的來源／權限欄位，不自行驗證交易真實性或執行資料庫過帳。

## 哪些刻意暫緩？

以下 **14 類**保留部分程式、資料表或歷史設計，均不列為目前可用功能，預設不啟用。暫緩代表產品範圍取捨，重新納入須另有需求、風險與驗證依據。

| 範圍 | 暫緩項目 |
|---|---|
| 跨國與申報 | 跨國合併、移轉訂價、永續報告、XBRL 監管申報 |
| 隱私與密碼技術 | 零知識證明、多方安全計算、量子密碼治理 |
| 資產與資金 | 數位資產、公有區塊鏈、流動性壓力測試、自主資金調度 |
| 網路與責任 | 基準比較網路、跨組織風險網路、AI 責任評分與仲裁 |

另已實作**唯讀財務查詢**：異常清單、應收／應付帳齡、依到期收付款排程估算的現金流，以及固定問題分類。這組選配功能預設停用，與上述 14 類分開管理，不列為目前已啟用的成果。

## 接下來還缺什麼？

1. **完成最新版本驗證**：補驗安全修正與完整會計、權限、瀏覽器及恢復流程，綁定來源版本與結果。
2. **接通第一組真實資料**：選定來源、取得授權，完成必要接入與文件辨識；用可核對答案檢查結果。
3. **補足專業與信任條件**：確認適用會計政策、外部佐證採信及金鑰治理，接通工作台交付與離線驗證工具。
4. **完成選定使用範圍的介面與維運**：補齊尚缺操作及部署／恢復驗收，明確列出排除情境。
5. **取得真實試用成果**：記錄人工流程基準、使用後結果與使用者回饋；目前沒有可宣稱的省時比例或客戶成果。
